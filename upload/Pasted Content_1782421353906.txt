## 2. PALETA DE COLORES — OBLIGATORIA

Esta paleta es fija e inamovible. Toda la UI debe derivarse de ella:

```
--color-primary:     #00BBD4   /* Cyan/teal vibrante — CTA, highlights, íconos activos */
--color-primary-light: #5DD6E6  /* Cyan claro — hovers, gradientes suaves, fondos de tarjetas */
--color-dark:        #334E68   /* Azul-gris oscuro — fondos principales, navbars, headers */
--color-surface:     #F5FAFF   /* Blanco azulado muy claro — backgrounds de secciones claras */
--color-muted:       #98A6B3   /* Gris azulado — texto secundario, bordes, metadatos */
--color-white:       #FFFFFF   /* Blanco puro — texto sobre fondos oscuros */
```

**Reglas de aplicación:**
- El fondo global alterna entre `#334E68` (secciones oscuras) y `#F5FAFF` (secciones claras)
- Los CTAs y elementos interactivos usan `#00BBD4`
- Los gradientes usan transiciones entre `#334E68` → `#00BBD4` o `#334E68` → `#5DD6E6`
- Los títulos sobre fondo oscuro son `#FFFFFF`; sobre fondo claro son `#334E68`
- El texto de cuerpo sobre fondo claro es `#334E68`; sobre fondo oscuro es `#F5FAFF`
- Los elementos de acento (líneas decorativas, iconos, tags) usan `#00BBD4`
- Nunca usar colores fuera de esta paleta salvo blanco puro y negro para contraste de texto

**Inspiración visual de las referencias:**
